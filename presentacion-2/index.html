Introducción

Las compuertas como decisiones físicas

Las compuertas lógicas son los bloques fundamentales de todo sistema digital.

En teoría son operadores del álgebra de Boole; en la práctica representan condiciones de seguridad, alarmas y automatizaciones.

Para cada compuerta se analiza

  1. Aplicación
  2. Problema que resuelve
  3. Entradas y salida
  4. Función lógica
  5. Tabla de verdad

Cinco casos son sistemas mixtos de dos etapas, con una tercera entrada de control.

Compuerta lógica

Salida

Actuador

El nivel lógico resultante acciona un equipo: motor, sirena, lámpara, bomba.

Lógica positiva

1 indica que la condición está presente (pulsador presionado, sensor activo, equipo encendido) y 0 que está ausente. Entradas y salida se interpretan por separado.

Para llevar

Conclusiones

01

Los 0 y 1 abstractos se traducen en acciones físicas: encender un motor, activar una alarma, evitar un accidente.

02

Elegir bien la compuerta define la lógica de decisión autónoma de un equipo, sin necesidad de un microprocesador.

03

Un error en la tabla de verdad puede significar la falla de un equipo o un riesgo para las personas.
